# english-word-flashcard-web
flashcard web app for english study

1. 실행은 온라인 주소로 연결해서 한다.
2. 단어장은 로컬에 있는 word.md (파일명 예시) 를 읽어서 공부한다.
3. 브라우저에서 단어장을 추가하거나 수정하면 내보내기를 해서 로컬 단어장을 업데이트 한다.
4. 브라우저 단어장의 진행상황도 같이 내보내기를 하면 다른 브라우저나 기기에서도 이어서 학습횟수 진행이 가능하다.
5. 웹주소 : https://english-word-flashcard-web.pages.dev/
